# Pipeline: the original build plan

History only. This was the July 2026 execution plan: eight phases, a 4-day schedule ending 2026-07-19, and a brief for one-shot generation. The schedule did not hold, and the code since then replaced parts of the design. **For what to build next, read [ROADMAP.md](./ROADMAP.md).** It carries the ranked backlog, the human gates still open, and the list of planned pieces that were cut.

Two lessons from the plan still apply, and ROADMAP keeps them as human gates:

- **Force the output onto a screen at the gates.** A model reports "import worked" because a function returned 200, and "graph built" because 400 rows were written. The parser test (B2: exactly 320 + 137 records) pins the first. The edge-reading gate (B3, ROADMAP AI-B) is still ahead.
- **Taste needs a human and a phone.** Whether Quest's door gate is fun (B4, ROADMAP QST-A) has no unit test.

The Anki parser traps that Phase 2 was built around live in [TDD §5](./TDD.md#5-the-anki-parser). The full original plan, with its diagram, schedule and generation brief, is in git history at `466384c:docs/PIPELINE.md`.
